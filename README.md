# Stackvenn — build kit

Spec pack for building and running **stackvenn.in** end to end with Claude Code.

- `START_PROMPT.md`: the one prompt to paste into Claude Code.
- `CLAUDE.md`: rules Claude Code loads automatically.
- `docs/`: PRD, design system, page designs, migration, reachability, marketing automation and the TODO plan.
- `data/blog-posts.json`: your existing article list (migration seed).
